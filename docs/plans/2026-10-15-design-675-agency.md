# Дизайн главной: 675 agency

## Бриф

- **Что:** портфолио по графическому дизайну и брендингу, бренд «675 agency».
- **Для кого:** владельцы бизнеса, которым нужны айдентика, упаковка и визуал.
- **Задача страницы:** показать работы и рассказать о студии.
- **Ограничения:** рамка сайта только чёрно-белая. Референс — mariavasilyeva.com (из контейнера недоступен).
- **Работы:** Linen Bio Science, Noise Craft, «Четыре японца» (серебро World Brand Design Society), «Мэллоу», neopet. Все в формате A, вертикальные.

## Идея

Сайт — это папка портфолио с разделителями. По правому краю идут закладки, как в проекте Linen Bio Science: каждая ведёт к своей работе, а закладка текущего раздела закрашена чёрным. Это единственный смелый элемент, всё остальное тихое, чтобы цветные работы были главными.

## Токены

### Цвет

| Имя        | Hex       | Роль                                            |
| ---------- | --------- | ----------------------------------------------- |
| `ink`      | `#000000` | текст, активная закладка, фон блока контактов   |
| `paper`    | `#ffffff` | фон, текст на чёрном                            |
| `graphite` | `#6b6b6b` | второстепенный текст (контраст 5.3:1 на белом)  |
| `silver`   | `#a3a3a3` | второстепенный текст на чёрном (контраст 8.3:1) |

Цвет на страницу приносят только работы.

### Шрифты

- **Unbounded** — знак «675 agency» и названия работ. Широкий геометричный гротеск, перекликается с округлыми формами neopet и «Мэллоу».
- **Golos Text** — основной текст, подписи, закладки.

Шкала по Брингхерсту (px): 14 · 18 · 21 · 36 · 60 · 144. Строка текста — не длиннее 60–65 знаков.

### Раскладка

Выравнивание по левому краю. Каждая работа — «разворот»: картинка на 7 колонок, текст на 5 колонок прилипает сверху, пока картинка прокручивается.

```
┌──────────────────────────────────────────┬──┐
│ 675                                      │67│
│ agency                                   │Li│ ← закладки на всю
│ Айдентика, упаковка и визуал для бизнеса │No│   высоту экрана,
├──────────────────────────────────────────┤4J│   активная — чёрная
│ ┌───────────────┐  Linen Bio Science     │Мэ│
│ │               │  Айдентика             │ne│
│ │   работа A4   │  Описание…             │О │
│ │               │                        │Св│
│ └───────────────┘                        │  │
├──────────────────────────────────────────┤  │
│ О нас: тезис          │ текст, услуги    │  │
├──────────────────────────────────────────┤  │
│ ███ чёрный блок: связаться ████████████  │  │
└──────────────────────────────────────────┴──┘
```

На телефоне закладки становятся горизонтальной полосой сверху, разворот — колонкой.

### Принципы

1. Смелость только в закладках. Ни карточек, ни теней, ни скруглений.
2. Работы показаны крупно и целиком, без кадрирования: формат A — часть каждой работы.
3. Подписи — обычный текст: название, тип работы, одна-две фразы. Без надписей капсом, цифр-маркеров и стрелок.
4. Одно движение: при загрузке закладки по очереди выдвигаются из края. При `prefers-reduced-motion` анимации нет.

## Проверка против шаблонов

- **Первый вариант** строился на огромном «675» на всю ширину экрана — это частый приём портфолио. Заменил его закладками, которые взяты из папки портфолио и из работы самого автора. Знак «675 agency» остался крупным, но спокойным.
- **Нумерованные закладки** (как 2–11 в Linen) — отказался: работы не последовательность, поэтому на закладках названия.
- **Шахматный порядок «картинка слева / справа»** — шаблон, отказался. Картинка всегда слева, как страницы в папке.
- **Тёмный фон + яркий акцент, газетные линейки, SaaS-карточки** — не используются. Линии есть только у закладок, где они показывают границы разделителей.
- **Тёмная тема** — отключена: ч/б бренд должен выглядеть одинаково.

## Что нужно от владельца

- Проверить описания работ: они написаны по изображениям.
- Текст «О нас», имя, почта, Telegram/Behance — ссылки пока пустые (`href="#"`).
