# Переделка главной: «Линия 675 км»

## Что изменилось в брифе

- Название на сайте остаётся **675 agency**; 675 — расстояние по прямой между Минском и Москвой. «Наша линия движется как бесконечность. У неё нет начала и конца».
- Агентство основали две выпускницы Школы дизайна ВШЭ.
- Референс: всё портфолио — одна строка мелких превью посреди страницы; при наведении из точки высыпается много картинок проекта.
- Контакты: minchenokwork@gmail.com, Telegram @kateminsk.
- На сайте три проекта с описаниями из PDF: книга «Лён», Linen Bio Science, «Мэллоу». Noise Craft, «Четыре японца» и neopet убраны по решению владельца.

## Идея

Референс и название говорят одно и то же: **линия**. Главная — это тонкая чёрная линия через весь экран, на которую, как бусины, нанизаны превью всех работ. Линия бесконечная: прокрутка колесом двигает её вбок, и после последней работы снова идёт первая — без начала и конца.

Наведение на превью — главный момент сайта: картинки этого проекта веером высыпаются над и под линией, рядом появляется название. Клик открывает страницу проекта.

Закладки и развороты из первой версии убираем: две смелые идеи на одной странице спорят друг с другом.

## Страницы

| Страница              | Что на ней                                                               |
| --------------------- | ------------------------------------------------------------------------ |
| `index.html`          | знак 675 agency, линия с работами, ссылки «О нас» и «Связаться»          |
| `project.html?p=<id>` | название, тип, описание, все картинки проекта колонкой; соседние проекты |
| `about.html`          | текст «О нас» и контакты                                                 |

Данные о проектах — в одном файле `src/data/projects.js`, чтобы новый проект добавлялся одной записью и картинками в `public/works/<id>/`.

## Раскладка главной

```
┌────────────────────────────────────────────────────┐
│ 675 agency                          О нас  Связаться│
│                                                    │
│                  ▓▓▓▓  ▓▓                           │ ← при наведении
│               ▓▓▓▓▓▓  ▓▓▓▓                          │   картинки проекта
│ ──▪▪─▪▪▪──▪▪▪▪─▪▪──[▪▪▪▪]──▪▪▪─▪▪──▪▪▪▪──▪▪─▪▪▪───  │ ← линия, едет вбок
│                 ▓▓▓  ▓▓▓▓▓                          │
│                  Мэллоу, упаковка                   │
│                                                    │
│ Брендинговое агентство                 312 км       │ ← счётчик пути
└────────────────────────────────────────────────────┘
```

- В углу — счётчик «0–675 км», который меняется при прокрутке линии и после 675 начинается заново. Это небольшая деталь, которая связывает название с движением.
- **На телефоне** линию листают пальцем, наведения нет: касание сразу открывает проект.

## Токены

Без изменений: `#000` / `#fff`, Unbounded + Golos Text. Цвет на страницу приносят только работы.

## Проверка против шаблонов

- Сетка карточек проектов — шаблон; заменена одной линией, как в референсе.
- Горизонтальные линейки на фоне референса не берём: на странице одна линия, и это сама идея.
- Движение одно и в ответ на действие — веер при наведении. Если в системе отключены анимации, картинки появляются без движения.
